# OneClickKnife
- Blender用ナイフ投影アドオンです。毎回ナイフ投影の手順をググるのが面倒で作った。

- 3D ビューポートから、ナイフ→対象　の順にオブジェクトをクリックし、右クリック「ナイフ投影」

## 注意

- 選択できるのは、投影先メッシュ 1 個と、カッター（メッシュまたはカーブ）1 個だけです。メニュー項目は条件を満たすときだけ有効になります。
- 標準の Knife Project と同様、現在の 3D ビューの方向が投影方向になります。
- 既定では表側だけを切ります。裏側も切りたい場合は、最後に実行した操作のパネルで **貫通** をオンにしてください。
